# БЛЕФ 0.1.0 — Windows / BLEF 0.1.0 — Windows

## Русский

Скачайте репозиторий кнопкой **Code → Download ZIP**, распакуйте архив и запустите `build/Играть.cmd`. При первом запуске скрипт извлечёт `BLEF.exe` из `BLEF-engine.zip`; рядом должен лежать `BLEF.pck`. Godot устанавливать не нужно. Если Windows запросит разрешение для локальной сети, разрешите доступ в частных сетях.

## English

Choose **Code → Download ZIP**, extract the repository and run `build/Играть.cmd`. On first launch, the script extracts `BLEF.exe` from `BLEF-engine.zip`; keep `BLEF.pck` in the same folder. Godot is not required. Allow access to private networks if Windows asks.

The game interface is in Russian. See the [main README](../README.md) for gameplay and controls.
