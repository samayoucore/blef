# UI icons

These PNGs are copies of the approved files from `Визуальный стиль/иконки`.
The originals are not edited. They are black silhouettes with transparent
backgrounds; `scripts/ui/icon_tint.gdshader` recolors visible pixels from the
alpha channel at runtime. The same asset can therefore be white on a dark
glass panel, green for an active action, or muted for a disabled action.
