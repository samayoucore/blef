# Изображения карточек

Готовые стороны карточек находятся в `res://assets/cards/front/` и сопоставлены с предметами в `data/items/card_textures.json`. В `front/` подключены все 41 предмет, включая исходный JPG блокнота без перекодирования. Общая обратная сторона — `res://assets/cards/back/card_back.png`.

Исходники в `Визуальный стиль/карточки` не изменяются. Лицевые изображения полностью непрозрачны и содержат светлый фон за пределами рамки; `scripts/visual/card_surface.gdshader` вырезает этот внешний фон общей маской с закруглёнными углами при рендере в 3D. Никакие PNG/JPG вручную не обрезаются и не перерисовываются.

До вскрытия карточка создаётся только у текущего владельца после открытия кейса. При финальном публичном вскрытии объект появляется обратной стороной и переворачивается на FRONT. Поэтому наличие всех текстур в клиентской сборке не раскрывает распределение предметов.
